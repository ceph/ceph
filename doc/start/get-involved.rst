=========================
 Ceph Community Channels
=========================

.. meta::
   :description: The mailing lists, chat channels, meetings, and trackers of the Ceph community.
   :ceph-page-type: reference
   :ceph-applies-to: squid, tentacle
   :ceph-reviewed: 2026-09
   :ceph-owner: docs

The Ceph community talks in these places. Pick the channel that fits
your question.

.. list-table::
   :header-rows: 1
   :widths: 20 45 35

   * - Channel
     - Use it for
     - Where
   * - **Blog**
     - Announcements and progress reports.
     - https://ceph.io/en/news/blog/
   * - **IRC**
     - Live chat with developers, mostly US Pacific daytime. ``#ceph`` for
       users and operators; ``#ceph-devel``, ``#ceph-dashboard``, ``#cephfs``
       for development.
     - - **Domain:** ``irc.oftc.net``
       - **Channels:** ``#ceph``, ``#ceph-devel``, ``#ceph-dashboard``,
         ``#cephfs``
   * - **Slack**
     - Live chat for user questions.
     - `Ceph Slack Invite`_
   * - **User List**
     - Questions and answers for users and operators (ceph-users@ceph.io).
     - - `User Subscribe`_
       - `User Archives`_
   * - **Devel List**
     - Development discussion (dev@ceph.io).
     - - `Devel Subscribe`_
       - `Devel Archives`_
   * - **Kernel Client**
     - Kernel client patches and discussion.
     - - `Kernel Client Subscribe`_
       - `Kernel Client Unsubscribe`_
       - `Kernel Client Archives`_
   * - **QA List**
     - Quality assurance.
     - `QA Subscribe`_
   * - **Community List**
     - Ceph User Committee and community topics.
     - - `Community Subscribe`_
       - `Community Archives`_
   * - **Bug Tracker**
     - File bugs and feature requests.
     - https://tracker.ceph.com/projects/ceph
   * - **Source Code**
     - Clone or download the code.
     - - https://github.com/ceph/ceph
       - https://download.ceph.com/tarballs/
   * - **Ceph Calendar**
     - Upcoming events.
     - https://ceph.io/en/community/events/
   * - **Contribute to Ceph**
     - How to contribute.
     - https://ceph.io/contribute/
